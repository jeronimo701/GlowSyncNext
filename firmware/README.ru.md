# Adalight для самодельной ленты

Два примера одной прошивки: Arduino Uno (ATmega328P) и классический ESP32 DevKit / esp32dev. Это не прошивка для коммерческого Skydimo; его перепрошивать не нужно. Для ESP32-S3/C3 и других плат требуется своя конфигурация PlatformIO.

Настройки по умолчанию: 81 WS2812B (RGB), 115200 бод, аппаратный порядок GRB. Программный предел FastLED — 1500 мА (оценочный), гашение через 2 секунды без полного кадра. Протокол — классический Adalight, не Skydimo.

## Подключение 5V WS2812B

```text
Внешний источник 5V ── предохранитель ── +5V ленты
GND источника ────────────────────────── GND ленты
        └────────────────────────────── GND контроллера

Uno D6 ── 330 Ом ────────────────────── DIN ленты
или
ESP32 GPIO18 ── 74AHCT125 (3.3V → 5V) ── 330 Ом ── DIN ленты
```

Уровнепреобразователь питается от 5V, его земля общая, соответствующий OE подключается к земле. На входе питания ленты можно поставить электролит около 1000 мкФ, соблюдая полярность. Данные подавать в DIN, не DOUT. Лента питается внешним источником, а не от USB/пина платы; для длинной ленты нужны подходящие провода и дополнительные точки питания. Не соединяйте два независимых выхода питания 5V между собой. Программный лимит не заменяет подходящий источник и защиту проводки.

Эта схема относится к 5V RGB WS2812B. 12V/24V, аналоговые и RGBW-ленты не поддерживаются этой конфигурацией.

## Сборка и загрузка

Установить PlatformIO, открыть firmware/adalight. В platformio.ini изменить LED_COUNT, SERIAL_BAUD, MAX_MILLIAMPS и GS_DATA_PIN под своё устройство. Для другого чипа/порядка изменить FastLED.addLeds в src/main.cpp. Приложение должно передавать RGB: аппаратная перестановка GRB уже выполняется прошивкой.

```text
pio run -d firmware/adalight -e uno
pio run -d firmware/adalight -e esp32
```

После проверки точной модели платы и COM-порта пользователь может загрузить прошивку:

```text
pio run -d firmware/adalight -e uno --target upload --upload-port COM5
pio run -d firmware/adalight -e esp32 --target upload --upload-port COM5
```

В приложении: Adalight, этот COM вручную, LED=81, baud=115200, порядок RGB. Для Uno разумно начать с 30 FPS. На AVR передача WS2812B временно блокирует прерывания, поэтому увеличение baud/FPS требует проверки на потери кадров. ESP32 предпочтительнее для больших лент. Watchdog и проверка длины/контрольного байта не позволяют показывать неполный кадр. Отключите остальные программы, занимающие порт.

Готовые файлы: uno/firmware.hex; esp32/firmware.bin — только приложение. Для чистой ESP32 также нужны bootloader.bin (0x1000), partitions.bin (0x8000), boot_app0.bin (0xe000); приложение — 0x10000. Надёжнее использовать upload через PlatformIO, который выбирает все файлы/параметры платы. Прошивка проверена компиляторами, а не физической загрузкой.

На Windows при длинном пути старый ESP32 GCC может выдавать CreateProcess. Используйте короткую папку проекта и PLATFORMIO_CORE_DIR; локальная сборка этого проекта успешно выполнена через временный короткий путь.

## WLED вместо своей прошивки

Можно установить WLED на поддерживаемую плату по официальной инструкции https://kno.wled.ge/basics/install-binary/ . Указать тип, физический порядок цветов, GPIO, число LED и лимит тока в WLED. Затем GlowSync Next → WLED/DDP → IP платы, UDP 4048, число LED, порядок RGB. В TPM2.NET режиме WLED нужно включить соответствующий приём и порт 65506.
